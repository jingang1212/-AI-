# 平台角色与权限说明

## 一、角色定义
| 角色 | 典型用户 | 关注内容 | 权限边界 |
|---|---|---|---|
| 环保局领导 | 属地生态环境部门 | 排放是否达标、趋势、法规依据、分析报告 | 只读。可查企业/排口/监测数据与报告，不可变更设备配置 |
| 安装运维 | 装机与运维工程师 | 设备状态、心跳、告警、配置参数、排障步骤 | 可读写。修改设备配置须二次确认并留痕 |
| 客服 | 企业对接人、内部支持 | 政策口径、流程问题、办理材料 | 只读知识库，不查企业数据 |

## 二、数据范围隔离
每个账号绑定「项目 → 企业 → 站点」三级范围：

1. 登录后仅返回授权范围内的企业列表；
2. 查询接口强制按授权企业过滤（`IN (授权企业ID)`），未授权直接返回空集，
   而不是返回「无权限」——避免通过错误码探测数据是否存在；
3. 导出功能单独校验范围，防止用导出接口绕过列表过滤；
4. 越权访问写入审计日志，同一账号 5 分钟内连续 3 次越权自动锁定。

## 三、写操作管控（AI 助手相关）
AI 助手代表用户执行写操作时，须满足全部条件：

1. 用户角色为「安装运维」且设备在其授权范围内；
2. 参数经白名单校验（只允许改波特率、上报地址、采样周期等已登记参数）；
3. 执行前向用户展示「将要修改什么、从什么值改成什么值」，等待人工确认；
4. 执行后写入操作日志（含原值、新值、操作人、时间、来源为 AI 助手）；
5. 禁止任何形式的表结构变更与批量删除语句。

## 四、审计与追溯
所有登录、查询、导出、写操作、AI 会话均记录：
账号、时间、IP、操作类型、目标对象、结果。
审计日志保留 3 年，任何人不得修改；AI 助手执行的操作额外记录会话 ID 与工具调用参数。
