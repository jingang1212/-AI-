# 分析报告与数据存证规范

## 一、报告适用范围
用于向企业、运维团队或监管部门提交的监测数据分析报告，
包括日报、周报、月报、专题分析报告与执法辅助报告。

## 二、报告必备要素
1. **报告编号**：规则为 `区县代码-年份-序号`，如 `110105-2026-0031`；
2. **监测对象**：企业全称、排口名称与编号、设备序列号（三者缺一不可，
   只写站号 ID 不足以作为监管文书依据）；
3. **分析时段**：精确到分钟，并说明数据完整率；
4. **数据来源**：平台数据库、设备本地原始文件，注明是否有补传数据（`backfill`）；
5. **判定依据**：引用的标准名称、条款与限值数值，须与知识库收录版本一致；
6. **结论**：明确「达标/超标/数据不足」，禁止使用「可能超标」等模糊表述；
7. **附件**：趋势图、超标时段明细、设备状态截图、现场照片（如需）。

## 三、区块链存证流程
1. 报告定稿后，计算报告文件与所用数据集的两份哈希（SHA-256）；
2. 将哈希（不含原始数据本身）上链，返回存证编号与区块高度；
3. 存证编号写入报告页脚，供任何第三方独立校验；
4. 数据被修改时哈希必然变化，校验即失败——这是「不可篡改」的技术依据。

注意：上链的是哈希，不是数据本身。数据量大时不可能整份上链，
且链上信息公开，直接上链会带来数据泄露风险。

## 四、归档与保存
- 报告与原始数据保存期限不少于 3 年（重点排污单位建议 5 年）；
- 归档目录按「企业 / 排口 / 年月」分层，文件名包含报告编号；
- 到期销毁须履行审批，形成销毁记录。
