# 环境保护法（节选）

第二十五条 企业事业单位和其他生产经营者应当按照国家有关规定安装使用监测设备，
保证监测设备正常运行，保存原始监测记录。

第四十二条 排放污染物的企业事业单位应当建立环境保护责任制度，明确责任人员。

违反本法规定，篡改、伪造监测数据，由县级以上人民政府环境保护主管部门责令改正，
处十万元以上一百万元以下的罚款。

## 《中华人民共和国大气污染防治法》（节选）
第九十九条 违反本法规定，有下列行为之一的，由县级以上人民政府生态环境主管部门责令改正
或者限制生产、停产整治，并处十万元以上一百万元以下的罚款；情节严重的，
报经有批准权的人民政府批准，责令停业、关闭：
（一）未依法取得排污许可证排放大气污染物的；
（二）超过大气污染物排放标准或者超过重点大气污染物排放总量控制指标排放大气污染物的；
（三）通过逃避监管的方式排放大气污染物的。

第一百条 有下列行为之一的，由县级以上人民政府生态环境主管部门责令改正，处二万元以上
二十万元以下的罚款；拒不改正的，责令停产整治：
（一）侵占、损毁或者擅自移动、改变大气环境质量监测设施或者大气污染物排放自动监测设备的；
（二）未按照规定安装、使用大气污染物排放自动监测设备或者未按照规定与生态环境主管部门的
监控设备联网，并保证监测设备正常运行的；
（三）未按照规定对所排放的工业废气和有毒有害大气污染物进行监测并保存原始监测记录的。

## 《排污许可管理条例》（节选）
第二十条 排污单位应当依照排污许可证规定，安装、使用、维护污染物排放自动监测设备，
并与生态环境主管部门的监控设备联网。
第二十一条 排污单位发现污染物排放自动监测设备传输数据异常的，应当及时报告生态环境主管部门，
并进行检查、修复。
第三十六条 排污单位篡改、伪造监测数据的，依照有关法律法规规定处理。

## 《刑法》相关条款
第二百二十九条 承担环境监测等职责的中介组织的人员，故意提供虚假证明文件，
情节严重的，处五年以下有期徒刑或者拘役，并处罚金。

## 企业合规要点
1. 监测设备必须与监管部门联网并保持正常运行，不是「装了就行」；
2. 原始监测记录必须保存，保存期限不少于 3 年（排污许可另有规定的从其规定）；
3. 发现数据异常应主动报告并修复，隐瞒异常本身可能构成违法；
4. 任何形式的篡改、伪造（含修改量程、时钟回拨、删除原始文件）均属严重违法。
