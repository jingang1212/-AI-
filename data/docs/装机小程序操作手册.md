# 装机小程序操作手册

装机小程序用于提交安装信息、配置串口服务器与测试连接，是现场装机的主入口。

## 一、提交工单
首次安装鉴定仪时必须先提交工单：
1. 点击底部导航栏「工单」→ 进入工单页；
2. 点击右下角「新建工单」，完整填写表单；
3. 提交后方可开始装机；
4. 装机完成后务必回到工单点「完成工单」，否则平台侧无法进入验收流程。

## 二、填写安装信息（装配页）
1. 在首页（装配页）点击「公司」，搜索并选择企业；
2. 点击「站点」，选择排口站点；没有目标站点时，**先点叉取消当前选择**，
   再点「选择站点」旁的加号新增（注意不要新增重复站点）；
3. 点击「设备」选择设备；没有则同样先取消再新增，避免重复；
4. 点击「盒子」选择鉴定仪；没有则新增，
   新增时把机壳贴纸上的**主机识别码**填入对应栏位；
5. 点击「串口服务器」选择或新增，新增时填写串口配置，
   注意**勾选重启后配置才生效**；
6. 选择该设备接入的两个串口；
7. 点击「提交配置」，确认信息无误后确认。

## 三、配置串口服务器
1. 用网线连接鉴定仪与串口服务器，
   确保鉴定仪**只与唯一一台未初始化的串口服务器**相连；
2. 在小程序新增串口服务器，填写对应串口配置；
3. 勾选「初始化」和「重启」，完成串口服务器初始化；
4. 点击提交。

## 四、测试连接
1. 点击「调试」页；
2. 选择公司、站点和鉴定仪，点击「测试连接」；
3. 选择设备及连接的串口，**监听数据在偶数口**；
4. 查看是否为实时数据、数据是否正常；
5. 若数据异常或无数据，依次检查：串口连接是否正确 → 串口配置是否正确 →
   波特率是否正确 → 线路是否松动（注意串口配置修改后必须勾选重启）；
6. 数据正常即连接成功。

## 五、向分析仪发送命令
1. 调试页 → 选择公司、站点、鉴定仪 → 测试连接；
2. 点击右下角「写入命令」；
3. 输入命令并等待新命令返回数据出现在页面；
4. 等待一段时间再判断数据是否正常——刚下发命令后可能出现短暂异常；
5. 若持续异常，检查命令是否写错或重复下发（重复命令会覆盖原配置）。

## 六、查看设备运行状态
1. 进入「测试页」→ 点击「盒子运行状态」；
2. 查看最后更新时间是否为鉴定仪启动之后的时间，
   是则说明设备正常运行，否则说明设备已重启或掉线。
