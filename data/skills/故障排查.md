# 技能：设备离线/异常现场排查

## 第一步：看云端心跳（不用去现场）
- 心跳完全中断 → 断电、4G 断网、上报地址被改；
- 有心跳但 `network_ok=0` → SIM 卡欠费 / 信号弱；
- 有心跳但 `process_running=0` → 采集程序未启动（断电重启后未自启最常见）；
- 心跳正常、数据不更新 → 协议/波特率问题（见《波特率配置》）。

## 第二步：现场三看
1. 看电源指示灯：不亮 = 断电，检查空开与适配器；
2. 看 4G 模块灯：红闪 = 无信号，检查天线与 SIM 卡座；
3. 看主板 RUN 灯：不闪 = 程序未运行，执行 `/opt/cems/bin/start.sh`。

## 第三步：恢复后验证
- 5 分钟内云端是否收到新心跳；
- 15 分钟内 `monitor_data` 是否恢复新增；
- 若断电导致数据缺失，按《数据补传规范》用本地缓存补传（设备本地缓存一般保留 30 天）。

## 升级条件
以下情况必须报研发：主板 RUN 灯常亮不闪且重复重启、设备无法进入配置页、更换分析仪后仍无帧。
