# 技能：电子证据鉴定仪串口波特率配置

适用场景：设备在线但采集程序取不到分析仪数据，或更换分析仪后数据不更新。

## 判断依据
1. 心跳正常、`process_running=1`，但 `monitor_data` 长时间无新增；
2. 设备日志出现 `frame timeout` / `checksum error` 连续刷屏（多为波特率或校验位不匹配）。

## 操作步骤
1. 现场上电，用随箱串口线连接设备调试口（DB9，默认 115200-8-N-1）；
2. 登录配置页 `http://192.168.10.1`（默认账号 admin / 设备铭牌后 8 位）；
3. 进入「采集参数 → 分析仪通道」；
4. 选择分析仪品牌（如 雪迪龙 SCS-900），系统会自动带出默认波特率；若不匹配，
   手动在 4800 / 9600 / 19200 / 38400 中逐个尝试，每改一次等待 30 秒看是否有数据帧；
5. 校验位与停止位必须与分析仪手册一致（常见：9600-8-E-1）；
6. 保存并重启采集进程：`/opt/cems/bin/collector restart`；
7. 观察云端 5 分钟内是否恢复数据。

## 常见坑
- 波特率改错不会报错，只表现为「无数据」，因此必须一次只改一个参数；
- 部分厂家的 Modbus 地址偏移不同（0 基 / 1 基），改完波特率仍无数据时要检查寄存器地址表。

## 补充：通过装机小程序改串口服务器波特率（现场最常用）
1. 登录装机小程序 → 首页 → 选择对应的「串口服务器」；
2. 点击「编辑」，找到目标串口（注意每台设备固定接两个串口，偶数口用于监听数据）；
3. 修改该端口 config 中的 `baud_rate`（数据位通常 8、停止位 1、校验位 None）；
4. **必须勾选「重启」再提交**，否则配置不生效——这是现场最高频的遗漏动作；
5. 回到调试页测试连接，确认数据变为正常实时数据。

### 串口服务器配置的数据结构（平台侧）
`h_uart_service.config` 字段为 JSON：
```json
{"uart": {"1": {"data_bit": 8, "stop_bit": 0, "check_bit": 0, "baud_rate": 9600},
          "2": {"data_bit": 8, "stop_bit": 0, "check_bit": 0, "baud_rate": 9600}}}
```
其中 `"1"`、`"2"` 代表端口号。**AI 助手修改该字段时只允许改目标端口的 `baud_rate`，
其余配置必须原样保留**，且执行前要向用户展示「端口 + 原值 → 新值」并等待确认。

## 补充：定位「到底该改哪个波特率」
出现无数据或乱码时，按链路逐段排除，不要一上来就改波特率：
1. 平台有心跳 → 说明 DTU/网络没问题；
2. 设备日志有 `frame timeout` → 说明分析仪没应答，问题在 RS485 段；
3. 用调试器直连分析仪，换几个常见波特率（4800/9600/19200/38400）各试 30 秒；
4. 能通的那个值就是分析仪实际波特率，再去改串口服务器对应端口；
5. 改完回读校验并观察 10 分钟，确认无 `checksum error`。
