# 技能：电子证据鉴定仪串口波特率配置

适用场景：设备在线但采集程序取不到分析仪数据，或更换分析仪后数据不更新。

## 判断依据
1. 心跳正常、`process_running=1`，但 `monitor_data` 长时间无新增；
2. 设备日志出现 `frame timeout` / `checksum error` 连续刷屏（多为波特率或校验位不匹配）。

## 操作步骤
1. 现场上电，用随箱串口线连接设备调试口（DB9，默认 115200-8-N-1）；
2. 登录配置页 `http://192.168.10.1`（默认账号 admin / 设备铭牌后 8 位）；
3. 进入「采集参数 → 分析仪通道」；
4. 选择分析仪品牌（如 雪迪龙 SCS-900），系统会自动带出默认波特率；若不匹配，
   手动在 4800 / 9600 / 19200 / 38400 中逐个尝试，每改一次等待 30 秒看是否有数据帧；
5. 校验位与停止位必须与分析仪手册一致（常见：9600-8-E-1）；
6. 保存并重启采集进程：`/opt/cems/bin/collector restart`；
7. 观察云端 5 分钟内是否恢复数据。

## 常见坑
- 波特率改错不会报错，只表现为「无数据」，因此必须一次只改一个参数；
- 部分厂家的 Modbus 地址偏移不同（0 基 / 1 基），改完波特率仍无数据时要检查寄存器地址表。
