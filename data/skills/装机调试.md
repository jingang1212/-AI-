# 技能：装机调试全流程（现场分步版）

## 阶段一：开工
1. 在装机小程序提交工单（不提交工单无法进入验收流程）；
2. 核对设备清单与型号，确认主机识别码（机壳贴纸）。

## 阶段二：接线与连通性测试
1. 用串口网络数据调试器确认分析仪有回帧；
2. 232 接 TX/RX/GND；485 接 A+/B-/GND（部分设备无 GND 则接 2 根）；
3. 颜色约定：黑=GND、黄=TX、蓝=RX；不通先对调黄蓝；
4. 测试通过后接入串口服务器（port1 进、port2 出到分析仪）。

## 阶段三：小程序配置
1. 装配页依次选公司 → 站点 → 设备 → 鉴定仪 → 串口服务器；
2. 新增记录时注意不要重复新增；鉴定仪需填主机识别码；
3. 选择设备接入的两个串口，提交配置；
4. 配置串口服务器时勾选「初始化 + 重启」。

## 阶段四：测试与收尾
1. 调试页 → 选择公司/站点/鉴定仪 → 测试连接；
2. 选择设备与串口，**监听数据在偶数口**，确认是实时正常数据；
3. 观察 10 分钟，确认心跳与数据双通道稳定；
4. 现场拍照（安装位置、铭牌、接线）上传；
5. 回到工单点「完成工单」。

## 阶段五：常见不通过项与处置
| 不通过项 | 处置 |
|---|---|
| 无数据 | 查串口连接 → 串口配置 → 波特率 → 线路 |
| 乱码 | 波特率错；或接线松动 |
| 只有部分数据正常 | 线序问题，对调黄蓝 |
| 配置改了没生效 | 忘记勾选重启 |
| 数据非实时 | 检查监听端口是否选在偶数口 |
