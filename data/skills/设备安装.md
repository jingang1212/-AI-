# 技能：电子证据鉴定仪安装规范（现场版）

## 安装前
1. 确认排口平台已具备 220V 电源与接地；
2. 核对设备编号与合同清单（编号即云端 `h_cems_device.id`，装错会导致数据挂错站点）；
3. 拍照记录安装位置（用于事后取证与验收）。

## 安装中
1. 分析仪 → 设备：RS485 屏蔽线，最长 1000 m，屏蔽层单端接地；
2. 设备 → 云端：默认 4G，弱信号区改用有线宽带；
3. 采样探头：距弯头下游 ≥ 2 倍管径，避免涡流影响测量；
4. 上电顺序：先分析仪、后采集器，避免上电瞬间帧丢失。

## 安装后
1. 在设备配置页填写站点编号（对应 `h_cems_station.id`）；
2. 观察心跳与数据双通道是否在 3 分钟内出现；
3. 采集一份现场照片 + 设备序列号照片上传到装机小程序，完成验收。
